# ניתוח דרישות הפרויקט ותוכנית פעולה

### מבוא
מסמך זה מנתח את דרישות משרד החינוך לפרויקט גמר 5 יח"ל באנדרואיד, כפי שהוגדרו במסמך `smartphonesProject-5.md`, ומשווה אותן למצב הנוכחי של אפליקציית `StepUp`.
מטרת המסמך היא לזהות פערים קיימים, לגבש תוכנית עבודה מסודרת להשלמתם, ולעקוב אחר התקדמות הפיתוח.

### תוכנית פעולה מפורטת

#### שלב 0: שדרוג ארכיטקטורת הניווט
*   **מטרה:** הפיכת האפליקציה למבנה מודרני מבוסס Fragments עם תפריט צד, כמענה לדרישות הפרויקט ולפידבק שהתקבל.
*   **סטטוס:** ✅ **הושלם**.

#### שלב 1: מימוש `SharedPreferences` במסך הגדרות
*   **מטרה:** הוספת נושא מתקדם (מסעיף 10) במינימום מאמץ.
*   **סטטוס:** ✅ **הושלם**. הקוד מומש ב-`SettingsFragment`.

#### שלב 2: יישום תזכורות מבוססות מיקום (משימה נוכחית)
*   **מטרה:** מימוש דרישות מתקדמות חסרות (`GoogleMaps`, `GPS`) והשלמת חזון האפליקציה.
*   **ביצוע:**
    1.  **הרשאות:** הוספת בקשת הרשאות מיקום (`ACCESS_FINE_LOCATION`).
    2.  **ממשק משתמש:** הוספת כפתור "בחר מיקום" במסך `EditGoalFragment`.
    3.  **שמירת המיקום:** עדכון מסד הנתונים כך שישמור קואורדינטות.
    4.  **Geofencing API:** שימוש במנגנון ליצירת "גדרות וירטואליות".
    5.  **BroadcastReceiver:** יצירת `LocationReminderReceiver` להפעלת ההתראה.
    6.  **שדרוג:** מימוש `MapFragment` להצגת כל המטרות מבוססות המיקום על מפה.

#### שלב 3: יישום מערכת מעקב התקדמות
*   **מטרה:** העלאת רמת המורכבות והשימושיות של הפרויקט (סעיף 11).
*   **ביצוע:**
    1.  **מסד נתונים:** יצירת טבלה חדשה, `GoalHistory`, לשמירת סטטוס ביצוע יומי.
    2.  **כפתורים בהתראה:** הוספת כפתורי "עשיתי" / "לא הפעם" להתראות.
    3.  **עדכון ממשק המשתמש:** הוספת `ProgressBar` לכרטיסיות המטרות ב-`HomeFragment`.
    4.  **שדרוג:** מימוש `ProgressFragment` להצגת התקדמות והיסטוריה חודשית.
